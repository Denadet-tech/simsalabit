# Simsalabit

**Dilo. Créalo. Juega. / Sag es. Bau es. Spiel es.**

Los niños crean juegos y mini-apps hablando, y los comparten con un enlace.

- **Versión de prueba (GitHub Pages):** `index.html` y `play.html` en esta carpeta. Se abre en
  `https://denadet-tech.github.io/simsalabit/`. Un adulto pone su clave de Anthropic en «Padres»
  (se guarda solo en ese móvil). Cada creación se comparte con un enlace que lleva el juego dentro.
- **Versión completa (Vercel):** carpeta `web/` (Next.js). Ver `web/README.md`.
